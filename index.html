DUX-ERP Intelligent Agent

A supervised multi-agent AI system built on top of the DUX-ERP enterprise platform. Users ask questions in plain language; a central orchestrator routes each request to a specialized agent, which answers with data, predictions and explanations, and proposes actions that a human approves before anything changes in the ERP.

  • Three sub-agents (Stock, Commercial, Finance) coordinated by a LangGraph ReAct orchestrator

  • Switchable LLM backbone: Claude API, local Ollama, or a QLoRA fine-tuned Llama 3.2 3B
  • FastAPI backend and Streamlit dashboard with human-in-the-loop validation
